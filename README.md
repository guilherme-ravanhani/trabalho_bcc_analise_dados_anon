# trabalho_bcc_analise_dados_anon
Análise exploratória de dados focada em diversidade e microagressões nas áreas de Ciência, Tecnologia, Engenharia e Matemática (CTEM). Através de Python (Pandas, Matplotlib, Seaborn) e dados anonimizados via Faker, este projeto investiga como gênero e etnia afetam a inserção de profissionais no mercado de trabalho e ambiente acadêmico.
